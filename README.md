# Jersey City Election Map

A map of Jersey City's 2025 mayoral election results by district.

The project uses GeoJSON district boundaries and election results from a CSV file to create an interactive map with OpenStreetMap as the base map.

## What it does

* Displays Jersey City election districts on a map
* Matches each district to its election results
* Determines which candidate received the most votes in each district
* Colors each district based on the winning candidate
* Makes the color more prominent when the winner has a larger share of the vote
* Combines split districts such as `32A` and `32B` into one district

## Project Structure

```text
.
├── districts/
│   ├── wardadistrict1.geojson
│   ├── wardadistrict2.geojson
│   └── ...
├── voter_data.csv
├── map.py
└── jersey_city_wards.html
```

### `districts/`

Contains the GeoJSON files for the Jersey City districts.

The filenames follow the district naming system. For example:

```text
wardadistrict1.geojson
```

represents:

```text
Jersey City Ward A District 1
```

### `voter_data.csv`

Contains the 2025 Jersey City mayoral election results by precinct.

### `map.py`

Reads the election data and GeoJSON files, matches the districts together, finds the winner of each district, and creates the map.

### `jersey_city_wards.html`

The interactive map generated by `map.py`.

## Setup

Install the required Python packages:

```bash
pip install folium geopandas pandas
```

Then run:

```bash
python map.py
```

This creates:

```text
jersey_city_wards.html
```

Open the HTML file in a browser to view the map.

## How the district matching works

The GeoJSON filenames are converted into the same format used by the election CSV.

For example:

```text
wardbdistrict5.geojson
```

becomes:

```text
Jersey City Ward B District 5
```

This is then matched against the `Precinct` column in `voter_data.csv`.

Some election precincts are split into multiple parts. For example:

```text
Jersey City Ward B District 32A
Jersey City Ward B District 32B
```

are combined into:

```text
Jersey City Ward B District 32
```

before calculating the district results.

## Map Colors

Each candidate has a different color.

The district is colored according to the candidate who received the most votes. The opacity is based on the winner's percentage of the total votes in that district.

A close election will therefore appear lighter, while a district with a stronger win will appear more prominently.
